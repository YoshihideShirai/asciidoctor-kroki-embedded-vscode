= Kroki Embedded Sample
:kroki-default-format: svg

== Expected Results

Open this document with `Asciidoctor Kroki Embedded: Open Preview`.

* The AsciiDoc extension renders PlantUML and Mermaid.
* This extension renders Graphviz, Nomnoml, Vega, Vega-Lite, WaveDrom, Bytefield, Pikchr, and Lini locally (`dot` is a Graphviz alias).
* D2, Seqdiag, C4PlantUML, Blockdiag, ERD, Ditaa, SvgBob, and Excalidraw display a local-rendering-not-supported message.
* No diagram source handled by this extension is sent to a Kroki server.

== Sequence

[plantuml]
----
@startuml
Alice -> Bob: Hello
Bob --> Alice: Hi
@enduml
----

[mermaid]
----
sequenceDiagram
  participant Author
  participant Preview
  Author->>Preview: Open AsciiDoc
  Preview-->>Author: Render Mermaid using the AsciiDoc extension
----

[seqdiag]
----
seqdiag {
  browser -> extension [label = "open preview"];
  extension -> kroki [label = "embed diagram"];
  kroki --> extension [label = "svg"];
}
----

== Architecture

[c4plantuml]
----
@startuml
!include <C4/C4_Container>

Person(author, "Author")
System_Boundary(vscode, "VS Code") {
  Container(extension, "Kroki Embedded Extension", "TypeScript")
  Container(preview, "AsciiDoc Preview", "Webview")
}
System_Ext(kroki, "Kroki renderer")

Rel(author, extension, "writes AsciiDoc")
Rel(extension, preview, "registers diagrams")
Rel(preview, kroki, "hydrates embedded SVG")
@enduml
----

[graphviz]
----
digraph G {
  rankdir=LR
  node [shape=box, style=rounded]
  adoc [label="AsciiDoc"]
  extension [label="VS Code extension"]
  preview [label="Preview"]
  svg [label="Embedded SVG"]

  adoc -> extension -> preview -> svg
}
----

[blockdiag]
----
blockdiag {
  default_shape = roundedbox;
  orientation = portrait;

  source -> register -> preview -> hydrate -> render;
}
----

== Vega

This uses the Vega renderer directly, independently of the Vega-Lite compiler.
All data is embedded in the specification.

[vega]
----
{
  "width": 320,
  "height": 120,
  "padding": 10,
  "data": [
    {
      "name": "table",
      "values": [
        { "label": "Graphviz", "value": 80 },
        { "label": "Nomnoml", "value": 55 },
        { "label": "WaveDrom", "value": 95 }
      ]
    }
  ],
  "scales": [
    { "name": "x", "type": "band", "domain": { "data": "table", "field": "label" }, "range": "width", "padding": 0.2 },
    { "name": "y", "type": "linear", "domain": [0, 100], "range": "height", "zero": true }

== D2

D2 is unsupported. This block displays an unsupported-format message without rendering or sending data to a server.

[d2]
----
direction: right
source: AsciiDoc
preview: Preview
svg: Embedded SVG
source -> preview -> svg
----
